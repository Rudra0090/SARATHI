# SARATHI — Supabase 1.8.2

Static HTML/CSS/JavaScript application. LocalStorage remains the offline cache and Supabase Auth/Postgres provide account-based cloud sync.

## Run
1. Extract the entire ZIP.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server (recommended) or serve the folder from a local web server.
4. Follow `SUPABASE_SETUP.md` if setting up a new deployment.

Keep the complete `assets/` folder. This release includes the existing backgrounds plus the current Ratha login assets.

## SARATHI Compass
The new Compass panel is an additive Drishti dashboard feature. It uses transparent local rules to suggest an upcoming scheduled item or the highest-priority open task. Its buttons open existing workspaces. It does not change task records or store additional personal data. It is not an AI model and its suggestions are guidance, not a guarantee.

## Data safety
The app's existing state key, data format, Supabase integration, workspaces, and backup behavior are retained. Back up important records before replacing any project files.

## Swasthya nutrition guidance (1.8.9)
